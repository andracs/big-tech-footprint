# Visualisering af techgiganternes CO2-udladninger

Denne side viser faktiske og forventede CO2e-udledninger for Microsoft, Google, Apple, Amazon, Meta/Facebook, NVIDIA og asiatiske techgiganter, samt datakort for AI-selskaberne Mistral AI, OpenAI, Anthropic og xAI.

Den bruger en interaktiv graf til at sammenligne rapporterede Scope 1+2+3-tal, målbaner og trendbaserede forventninger mellem 2020 og 2026.

Som standard vises kun selskaber med **stigende** udledninger. Emojis viser tendensen: 🔴📈 stigende, 🟡📉 faldende men ikke i mål, 🔬 ingen årstal men åben livscyklusanalyse, ⚪❔ ingen tal.

Se [FAKTATJEK.md](FAKTATJEK.md) for rettelser, kilder og åbne punkter (senest 2. oktober 2026).
